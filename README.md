# فراز انرژی اطلس — پروژهٔ کامل Next.js

این بسته شامل صفحهٔ اصلی، سه کاتالوگ، صفحهٔ چاه کشاورزی و استایل آبی نفتی است. داده‌ها و قیمت‌ها در `src/app/_solar/catalogs.ts` و استایل در `src/app/_solar/solar.module.css` قرار دارند.

## اجرا روی کامپیوتر

با Node.js 24، از کنار `package.json` اجرا کنید:

```bash
npm ci
npm run dev
```

صفحه را در `http://localhost:3000` باز کنید.

## انتشار در GitHub Pages

1. ZIP را استخراج کنید و **محتویات داخل آن** را در ریشهٔ مخزن قرار دهید، نه خود ZIP و نه یک پوشهٔ تودرتو. پوشهٔ مخفی `.github` را هم کپی کنید؛ فایل گردش‌کار در `.github/workflows/deploy.yml` است.
2. در مخزن، به **Settings → Pages** بروید و **Source** را روی **GitHub Actions** بگذارید.
3. فایل‌ها را روی شاخهٔ `main` یا `master` پوش کنید. برای شاخهٔ دیگر یا اجرای مجدد، از **Actions → Deploy to GitHub Pages → Run workflow** استفاده کنید.
4. بعد از موفقیت اجرای گردش‌کار، آدرس سایت را در **Settings → Pages** باز کنید.

گردش‌کار پروژه را می‌سازد، پیشوند آدرس سایت را از تنظیمات Pages می‌گیرد و فقط خروجی `out/` را منتشر می‌کند. پوشه‌های `node_modules`، `.next` و `out` را به Git اضافه نکنید. اگر مخزن فعلی فایل‌های دیگری دارد، قبل از جایگزینی `package.json` و تنظیمات Next.js نسخهٔ پشتیبان بگیرید یا این بسته را در مخزنی جداگانه امتحان کنید.
